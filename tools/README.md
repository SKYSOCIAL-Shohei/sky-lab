# tools/

## guard.py — 公開前セキュリティ検査

公開されるファイルに、外に出してはいけない情報が含まれていないか検査する。

### 何を止めるか

| 対象 | 理由 |
|---|---|
| IPアドレス | サーバーの所在が特定される |
| 自社のホスト名 | 存在するホストは偵察の起点になる |
| DNSレコードの値、SPF、DKIM | メール認証やDNS構成が特定される |
| 所有権確認トークン | 第三者に所有権を主張される恐れ |
| APIキー、パスワード、秘密鍵 | 認証情報の漏洩 |
| 利用しているホスティングの内部名 | 構成が特定される |

サイト自身の公開URL（lab.sky-social.com、www.sky-social.com）は許可する。

事業者名とファイルパスは警告扱い。止めはしないが、必要か再考する。

### 実行

```
python3 tools/guard.py
```

終了コード 0 で合格、1 で不合格。**不合格のものは公開しない。**

### 自動実行

`.github/workflows/guard.yml` により、mainへの反映時に自動で走る。
不合格なら赤いバツが付く。目視に頼らず、ここで止める。

### 検査自体の検証

この検査が機能しているかを確かめるには、意図的に違反を含むファイルを
作って実行し、検出されることを確認する。
**検査されていない検査は、無いよりも危険である。**
